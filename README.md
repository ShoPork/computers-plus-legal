# מחשוב + סלולר להבים · Computers Plus & Cellular Lehavim — legal and support pages

Published with GitHub Pages. Linked from the app (Profile → About, checkout terms) and the store listings.

- `terms.html` — terms and conditions
- `accessibility.html` — accessibility statement (IS 5568 / WCAG AA)

These files are generated: edit `legal-site/content/` in the app repo (ShoPork/computers-plus), run `python3 legal-site/build.py`, then copy the generated pages here.
